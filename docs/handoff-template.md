# Hum Project Handoff Template (Thread 移行用)

新 thread / 別 session で context を即時復元するための template。各 phase 完了時に同期更新。

## Format

HUM PROJECT HANDOFF - Thread 移行用

Phase: <現在 phase 名>
Status: <進行中 / 完了 / blocked>

CLAUDE.md 更新履歴 (直近 3 件):
1. <YYYY-MM-DD>: <更新内容>
2. <YYYY-MM-DD>: <更新内容>
3. <YYYY-MM-DD>: <更新内容>

重要ルール (抜粋、CLAUDE.md mistake list から):
- <rule 1>
- <rule 2>
- <rule 3>

現在 open issue:
- <issue 1>
- <issue 2>

Next Step (Yusuke 確認):
- <action 1>
- <action 2>

前 thread reflection:
- <reflection summary>
- <key decision 履歴>

## 運用 rule
- 毎 phase 完了時に同期更新 (CLAUDE.md + handoff-template.md)
- 新 thread 開始時に最初に貼り付け
- Yusuke memory との重複避け、handoff-template は技術 context、memory は user preference 中心
