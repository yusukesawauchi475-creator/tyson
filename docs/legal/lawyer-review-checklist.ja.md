# 弁護士確認チェックリスト

本ドキュメントは、Hum のプライバシーポリシー（privacy-policy.ja.md）および利用規約（terms-of-use.ja.md）について、専門弁護士による確認を受ける際の重点項目をまとめたものです。

## 確認対象ドキュメント
- docs/legal/privacy-policy.ja.md
- docs/legal/terms-of-use.ja.md

## 重点確認項目（5点）

### 1. 事業者名
- ビザステータス（米国 GC 申請中）に紐づく運営主体の確定
- 個人事業 / 米国法人 / 日本法人 / その他のうち、どの形態を運営主体とするか
- 個人情報取扱事業者としての登録要否
- 影響範囲：プライバシーポリシー第1条・第14条、利用規約第1条・第13条

### 2. 健康推論機能（要配慮個人情報）
- 将来、音声・日記から認知症等の健康状態を推論する機能を実装する場合の法的要件
- 要配慮個人情報の取得・利用に係る APPI 上のオプトイン要件
- 別建ての同意取得フロー・別規約の必要性
- 推論精度・誤検知時の責任範囲
- 医療機器プログラム該当性（薬機法）の確認
- 影響範囲：プライバシーポリシー第3.3条、利用規約第7条

### 3. 故人データへのアクセス権
- 本人逝去後の音声・写真・日記等のデータの法的取扱い
- 「本人生前設定」「家族の合理的申出」「所定確認手続」の法的妥当性
- 相続財産としての位置づけ
- 家族からの開示・削除・継承請求への対応プロセスの法的妥当性
- デジタル遺品法制の参照
- 影響範囲：プライバシーポリシー第10条

### 4. 高齢者の同意能力
- 高齢利用者の同意能力に懸念がある場合の取扱い
- 家族・支援者による代理同意の法的可否
- 認知症診断後の同意の取扱い
- 成年後見制度との関係
- 同意能力確認プロセスの設計
- 影響範囲：プライバシーポリシー第11条、利用規約第3条

### 5. 準拠法・管轄裁判所
- 米国在住・GC 申請中の founder、日本市場をターゲットとするサービスの場合の準拠法選択
- 管轄裁判所の専属合意の妥当性
- 国際的なデータ取扱い（GDPR・他国法令）への対応必要性
- APPI（個人情報の保護に関する法律）の適用範囲
- 影響範囲：プライバシーポリシー第15条、利用規約第12条

## その他確認推奨項目（参考）

- 未成年者の利用同意要件（利用規約第3.2条）
- 責任制限範囲・損害賠償上限（利用規約第10条）
- 連絡先・お問い合わせ窓口の形式（メール / フォーム等）
- 改訂時の通知方法の十分性
- 第三者業務委託先（Firebase / Vercel / OpenAI 等）の安全管理措置の文書化要件
- 退会時の「合理的な期間」「合理的な範囲」等の文言の具体化要否
